# 📅 Problem of the Day

This folder is the home for daily LeetCode challenges and their solutions.

## Suggested organization

Create a folder or file for each challenge, using a date or problem title so the journey stays easy to navigate.

For every problem, try to include:
- Problem name and LeetCode link
- Problem statement or a short summary
- Your approach and key insight
- Solution code
- Time and space complexity
- What you learned

## Daily reminder

Show up, understand the problem, give it an honest attempt, and learn from the result. Consistency beats intensity.

**One problem at a time. Keep going.** 🚀
